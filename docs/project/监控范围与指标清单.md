# 监控范围与指标清单

## 1. 监控范围

### 1.1 节点层
- **监控对象**：Linux虚拟机（IP: 192.168.213.141）
- **采集方式**：Node Exporter
- **监控内容**：CPU、内存、磁盘、网络、系统负载

### 1.2 容器层
- **监控对象**：Docker容器
- **采集方式**：cAdvisor
- **监控内容**：容器CPU、内存、磁盘IO、网络IO、重启次数

### 1.3 应用层
- **监控对象**：Nginx Web服务器
- **采集方式**：Promtail + Nginx日志
- **监控内容**：请求量、响应时间、5xx错误率、访问日志

### 1.4 组件层
- **监控对象**：监控系统组件
  - Prometheus（指标存储）
  - Loki（日志存储）
  - Grafana（可视化）
  - Alertmanager（告警管理）
- **监控内容**：进程存活状态、资源使用率、服务健康状态

## 3. 监控架构

```plain
[被监控服务器] 
    ├── Node Exporter (采集CPU/内存/磁盘) ──┐
    ├── Cadvisor (采集容器指标) ───────────┼──► [Prometheus] ──► [Grafana]
    └── Nginx Log ──► [Promtail] ──► [Loki] ──┘
                                              │
[告警通知] ◄── [Alertmanager] ◄──────────────┘
```

### 3.1 数据流向
1. **数据采集**：
   - Node Exporter：采集主机指标
   - cAdvisor：采集容器指标  
   - Promtail：采集应用日志

2. **数据存储**：
   - Prometheus：存储时序指标数据
   - Loki：存储日志数据

3. **数据可视化**：
   - Grafana：统一可视化平台

4. **告警管理**：
   - Alertmanager：告警规则管理和通知

## 4. 告警策略

### 4.1 告警级别
- **P0（紧急）**：系统宕机、核心服务不可用
- **P1（高）**：性能严重下降、错误率激增
- **P2（中）**：性能下降、资源使用率接近阈值
- **P3（低）**：潜在问题、需要关注

### 4.2 告警通知渠道
- 邮件通知
- 钉钉/企业微信通知
- 短信通知（仅P0/P1级别）

### 4.3 告警抑制规则
- 避免告警风暴
- 关联告警合并
- 工作时间和非工作时间差异化告警

## 5. 监控目标

1. **故障快速发现**：系统异常5分钟内发现
2. **性能问题预警**：资源使用率接近阈值时提前预警
3. **容量规划支持**：基于历史数据进行容量预测
4. **安全事件监控**：异常访问和攻击行为监控
5. **业务影响评估**：监控业务关键指标
